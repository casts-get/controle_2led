# Controle de 2 LEDs

O projeto foi desenvolvido utilizando um botão para controlar dois LEDs. Cada vez que o botão é pressionado, o sistema passa para uma nova etapa. No primeiro acionamento, o LED 1 é ligado. No segundo, o LED 1 é desligado e o LED 2 é ligado. No terceiro acionamento, os dois LEDs permanecem desligados. No quarto, o LED 1 é ligado novamente, iniciando o ciclo mais uma vez.

* O botão é utilizado como entrada pelo pino 8;
* O LED 1 é controlado pelo pino 10;
* O LED 2 é controlado pelo pino 13.
